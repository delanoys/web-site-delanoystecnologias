Comando shutdown (CMD)

Comandos básicos para diagnóstico y administración rápida en Windows. Útil cuando PowerShell no está disponible.

Ejemplos rápidos 

                                :: Mostrar configuración IP
                                ipconfig /all

                                :: Probar conectividad
                                ping google.com

                                :: Listar rutas de red
                                route print

                                :: Apagar el equipo (requiere permisos)
                                shutdown /s /t 30  && echo "Apagado programado en 30s"
                                        
shutdown /r /t 0

Comandos PowerShell

PowerShell ofrece mayor potencia y scripting para automatizar tareas. Ejecutar como administrador para acciones de sistema.

Snippets útiles 

                                # Listar procesos y filtrarlos
                                Get-Process | Sort-Object CPU -Descending | Select-Object -First 10

                                # Listar servicios
                                Get-Service | Where-Object {$_.Status -eq 'Running'}

                                # Reiniciar equipo local
                                Restart-Computer -Force

                                # Apagar equipo local
                                Stop-Computer -Force

                                # Ejemplo: apagar después de 1 minuto
                                Start-Sleep -Seconds 60; Stop-Computer -Force

Guarda scripts en .ps1 y establece la política de ejecución solo si confías en el contenido: Set-ExecutionPolicy RemoteSigned.

Inicio Seguro (Modo seguro con bcdedit)

Comandos para iniciar Windows en modo seguro y restaurar el inicio normal.

bcdedit /set {default} safeboot minimal
shutdown /r /t 0
# Después de reparar el sistema, vuelve al modo normal:
bcdedit /deletevalue {default} safeboot
