🔍 Análisis de su Ejercicio Local (¡Punto de Control Crítico!)

En sus pruebas locales ejecutó tres variantes de código en Python e imprimió los resultados usando el texto print('Total platos:', cursor.fetchone()[0]). Analicemos por qué la terminal devolvió esos valores:

Consulta 1: SELECT COUNT(*) FROM platos

Resultado: 26. Correcto. La función devuelve una sola fila con una sola columna conteniendo el número total de registros.

Consulta 2: SELECT * FROM platos

Resultado: 1. ¿Por qué? El método .fetchone() extrae únicamente la primera fila del cursor. La posición [0] corresponde a la primera columna de esa fila, que es el ID autoincremental (Plato ID: 1).

Consulta 3: SELECT nombre, descripcion FROM platos

Resultado: Calentado Valluno. Explicación idéntica. .fetchone() extrajo la primera fila disponible, y el índice [0] tomó la primera columna solicitada, que en este caso es el nombre del primer plato.

🔄 Cambio de Mentalidad: Oracle vs. SQLite

Característica Oracle Database SQLite Local
Arquitectura Cliente-Servidor (Multi-proceso pesado en red). Embebida (Una biblioteca en C dentro del código, sin servidor).
Almacenamiento Esquemas complejos repartidos en archivos .DBF (Tablespaces). Un archivo ordinario monolítico (Ej: restaurante.db).
Tipado de datos Estricto y rígido (VARCHAR2, NUMBER, DATE, etc.). Dinámico (Afinitad de tipos: TEXT, NUMERIC, INTEGER, REAL, BLOB).
Concurrencia Avanzada a nivel de bloques de filas, ideal para miles de usuarios. Bloquea el archivo completo durante escrituras. Excelente para lectura masiva.

🐚 Módulo 1: Consultas Avanzadas desde la Terminal (Bash)

A diferencia de Oracle SQL*Plus, el cliente de consola de SQLite permite inyectar consultas inline directas o trabajar con comandos de sistema que inician con un punto (.).

Comando 1: Formatear la consola para lectura humana

Por defecto, SQLite usa barras verticales como separadores. Cambiémoslo a un modo tabla limpio con encabezados visibles:

sqlite3 -column -header restaurante.db "SELECT nombre, precio, categoria FROM platos LIMIT 3;"

Comando 2: Agrupamientos de negocio (Agregación)

¿Cuántos platos tenemos por cada categoría y cuál es el precio promedio en el menú?

sqlite3 -box restaurante.db "SELECT categoria, COUNT(*) as cantidad, AVG(precio) as precio_promedio FROM platos GROUP BY categoria;"
* Nota: El parámetro -box dibuja bordes unicode de forma gráfica y elegante en distribuciones Linux modernas como Elementary OS.

🐍 Módulo 2: Dominando el Cursor e Iteraciones en Python

Para actualizar sus conocimientos, es vital aprender a extraer múltiples filas y mapear columnas. A continuación se presentan los tres patrones estándar de desarrollo en Python:

🔥 Patrón A: Iteración Eficiente con un bucle For (Evita saturar la RAM)

Ideal para listar el menú completo sin cargar todas las filas en la memoria de la laptop a la vez.

import sqlite3

conn = sqlite3.connect('restaurante.db')
cursor = conn.cursor()

# Ejecutar proyección de platos a la carta
cursor.execute("SELECT nombre, precio FROM platos WHERE categoria = 'carta'")

print("📋 PLATOS A LA CARTA:")
# El cursor es un iterador nativo, podemos recorrerlo directamente fila por fila
for fila in cursor:
    nombre_plato = fila[0]
    precio_plato = fila[1]
    print(f"➔ {nombre_plato}: ${precio_plato:,.0f} COP")

conn.close()

📦 Patrón B: Uso de .fetchall() (Extraer toda la matriz de datos de golpe)

Útil cuando necesitas contar de forma exacta o pasarle un lote completo de registros al agente de LangChain.

import sqlite3

conn = sqlite3.connect('restaurante.db')
cursor = conn.cursor()

cursor.execute("SELECT nombre FROM platos WHERE categoria = 'bebidas'")
# fetchall() vacía el cursor y transforma todo el resultado en una Lista de tuplas
todas_las_bebidas = cursor.fetchall()

print(f"Tenemos {len(todas_las_bebidas)} bebidas registradas:")
for bebida in todas_las_bebidas:
    print(f"• {bebida[0]}")

conn.close()

🛡️ Patrón C: Consultas Blindadas con Parámetros (Evita Inyección SQL)

Crucial para las herramientas de la IA. Jamás se debe usar concatenación de cadenas (f"...") para variables de usuario.

import sqlite3

conn = sqlite3.connect('restaurante.db')
cursor = conn.cursor()

# Supongamos que esta variable llega desde el webhook de WhatsApp del cliente
categoria_cliente = "desayunos"

# Usamos el marcador de posición de SQLite (?) para sanitizar la consulta
query = "SELECT nombre, precio FROM platos WHERE categoria = ? AND disponible = 1"

# Pasamos los parámetros dentro de una TUPLA obligatoria (categoria_cliente,)
cursor.execute(query, (categoria_cliente,))
resultados = cursor.fetchall()

print(f"🍳 RESULTADO DE BÚSQUEDA PARA: {categoria_cliente.upper()}")
for r in resultados:
    print(f"- {r[0]} | Precio: ${r[1]}")

conn.close()

🚀 Laboratorio Práctico de Actualización Directa

Copie y pegue este comando unificado en la consola de su Elementary OS para ejecutar un script de Python avanzado que transforma las tuplas crudas en Diccionarios estructurados:

python3 -c "
import sqlite3

def dict_factory(cursor, row):
    d = {}
    for idx, col in enumerate(cursor.description):
        d[col[0]] = row[idx]
    return d

conn = sqlite3.connect('restaurante.db')
conn.row_factory = dict_factory  # ¡MAGIA! Transforma tuplas en diccionarios
cursor = conn.cursor()

cursor.execute('SELECT nombre, precio, categoria FROM platos WHERE categoria=\"especiales\" LIMIT 2')
for plato in cursor.fetchall():
    print('Nombre:', plato['nombre'], '➔ Precio:', plato['precio'], 'COP [Cat:', plato['categoria'].upper(), ']')
conn.close()
"
