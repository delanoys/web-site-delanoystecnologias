Aprendiendo Docker en AWS EC2 Free Tier

Crea tu entorno Ubuntu y domina Docker en la nube

¿Qué es AWS EC2 Free Tier?

AWS EC2 Free Tier te permite crear y usar una máquina virtual Ubuntu real en la nube sin costo durante 12 meses. Con esta opción puedes instalar y manejar Docker directamente desde tu navegador o usando SSH.

Ventajas del Free Tier

  • Gratis por 12 meses: tipos t2.micro o t3.micro.
  • Control total: administra Ubuntu y Docker sin limitaciones.
  • Accesible: usa la terminal desde tu navegador o conecta por SSH.

🚀 Cómo empezar

  1. Entra a AWS y accede al servicio EC2.
  2. Crea una nueva instancia y elige la imagen Ubuntu Server 22.04.
  3. Conéctate a la instancia mediante SSH o el terminal web de AWS.
  4. Instala Docker con el siguiente comando: 
    
sudo apt update && sudo apt install docker.io -y

💻 Comandos Docker por Nivel

🧩 Nivel Básico


# Ver versión de Docker
docker --version
# Descargar una imagen
docker pull ubuntu
# Listar imágenes
docker images
# Ejecutar un contenedor
docker run -it ubuntu bash
# Ver contenedores
docker ps
# Salir
exit

⚙️ Nivel Intermedio


# Contenedor en segundo plano
docker run -d nginx
# Ver logs
docker logs nginx
# Volúmenes
docker volume create datos
# Red personalizada
docker network create redlocal

🚀 Nivel Avanzado


# Construir imagen
docker build -t mi_imagen .
# Optimizar
docker system prune -a
# Exportar imagen
docker save -o mi_imagen.tar mi_imagen
# Escalar servicios
docker-compose up -d --scale web=3
