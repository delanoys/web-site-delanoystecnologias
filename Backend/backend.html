¿Qué es el Backend?

El backend es la lógica del servidor: recibe peticiones, procesa datos, accede a bases de datos y devuelve respuestas seguras y eficientes.

    Prácticas guiadas

    API REST de Tareas

    Construye una API CRUD con autenticación por tokens, validación y pruebas.

    Requisitos
    • Endpoints: /auth, /tasks
    • DB: tablas users, tasks
    • Pruebas: integración y unitarias

    Servicio de Mensajería

    Implementa colas (ej. RabbitMQ) para procesar trabajos en segundo plano.

    Requisitos
    • Productor/Consumidor
    • Idempotencia
    • Reintentos y DLQ

    Glosario

    API
    Interfaz para que dos sistemas se comuniquen, generalmente sobre HTTP.
    REST
    Estilo arquitectónico que usa recursos, verbos HTTP y representaciones.
    Idempotencia
    Propiedad por la cual ejecutar la misma operación múltiples veces produce el mismo resultado.
    Observabilidad
    Capacidad de entender el estado interno del sistema con métricas, logs y trazas.
