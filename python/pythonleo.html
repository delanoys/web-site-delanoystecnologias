¿Qué es Python?

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general, creado por Guido van Rossum en 1991. Se destaca por su sintaxis clara y legible, lo que lo hace ideal para principiantes y expertos.

Características principales:

  • Sintaxis simple y legible
  • Interpretado (no requiere compilación)
  • Multiplataforma
  • Gran comunidad y ecosistema
  • Amplia variedad de librerías

Historia y Evolución

Origen

Python fue creado por Guido van Rossum en 1989 y lanzado públicamente en 1991. El nombre proviene del grupo cómico británico Monty Python, no de la serpiente.

Versiones Importantes

  • Python 2.0 (2000): Introducción de garbage collection
  • Python 2.7 (2010): Última versión de Python 2
  • Python 3.0 (2008): Cambios significativos, versión recomendada
  • Python 3.12 (2023): Versión actual más estable
