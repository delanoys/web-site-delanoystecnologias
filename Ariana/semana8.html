Semana 8: Tuplas en Python

¿Qué son las Tuplas?

Una tupla es una estructura de datos similar a una lista, pero con dos características importantes:

  • Es inmutable (no se puede modificar después de crearla).
  • Se define usando paréntesis ().
# Ejemplos sencillos de tuplas
colores = ("rojo", "verde", "azul")
coordenadas = (10, 20)
estudiante = ("Ariadna", 20, 4.5, True)

print(colores)
print("Primer color:", colores[0])

Ventajas de las tuplas: Son más rápidas que las listas y se usan cuando los datos no deben cambiar (ej: coordenadas, datos fijos, retorno de múltiples valores).

Empaquetado y Desempaquetado

# Empaquetado
persona = "Ariadna", 20, 1.65, True

# Desempaquetado
nombre, edad, altura, es_estudiante = persona

print(nombre, edad, altura)

Ejercicio 1 - Función con Tupla

Crea una función que reciba una tupla con (nombre, edad, nota) y retorne un mensaje según la nota.

def analizar_estudiante(datos):
    nombre, edad, nota = datos
    if nota >= 4.0:
        return f"{nombre} tiene un excelente desempeño ({nota})"
    elif nota >= 3.0:
        return f"{nombre} aprobó con nota {nota}"
    else:
        return f"{nombre} necesita mejorar ({nota})"

estudiante = ("Hever", 22, 4.3)
print(analizar_estudiante(estudiante))
