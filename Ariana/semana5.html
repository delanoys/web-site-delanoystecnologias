Semana 5: Primer Parcial

📌 Esta semana es de evaluación.
Repasa los temas de las semanas 1 al 4.

Resumen de Temas del Primer Parcial

  • Variables y tipos de datos
  • Operadores aritméticos
  • Entrada y salida de datos (input/print)
  • Condicionales simples, dobles y múltiples (if, else, elif)

🔍 Ejemplos de Repaso

# Ejemplo 1: Combinación de temas
nombre = input("Nombre: ")
edad = int(input("Edad: "))

if edad >= 18:
    print(f"{nombre}, eres mayor de edad")
else:
    print(f"{nombre}, eres menor de edad")
# Ejemplo 2: Clasificación por rangos
nota = float(input("Nota final: "))

if nota >= 4.5:
    print("Excelente")
elif nota >= 3.5:
    print("Bueno")
elif nota >= 3.0:
    print("Aceptable")
else:
    print("Reprobado")

✍️ Ejercicios de Repaso para el Parcial

Ejercicio 1

Pide tres números y determina cuál es el mayor.

a = int(input("Número 1: "))
b = int(input("Número 2: "))
c = int(input("Número 3: "))

if a >= b and a >= c:
    print("El mayor es", a)
elif b >= c:
    print("El mayor es", b)
else:
    print("El mayor es", c)

Ejercicio 2

Calcula el promedio de 4 notas y determina si aprueba (promedio ≥ 3.0).

n1 = float(input("Nota 1: "))
n2 = float(input("Nota 2: "))
n3 = float(input("Nota 3: "))
n4 = float(input("Nota 4: "))

promedio = (n1 + n2 + n3 + n4) / 4
print("Promedio:", round(promedio, 2))

if promedio >= 3.0:
    print("¡Aprobaste!")
else:
    print("Reprobaste")

Ejercicio 3 (Nivel Parcial)

Crea un programa que pida un número y diga si es par o impar, y si es positivo o negativo.

num = int(input("Ingresa un número: "))

if num % 2 == 0:
    print("Es par")
else:
    print("Es impar")

if num > 0:
    print("Es positivo")
elif num < 0:
    print("Es negativo")
else:
    print("Es cero")
