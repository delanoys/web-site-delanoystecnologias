Semana 7: Listas en Python

1. Creación, Indexación y Slicing

notas = [4.2, 3.8, 4.5, 3.1]
print(notas[0])           # Primer elemento
print(notas[-1])          # Último elemento
print(notas[1:3])         # Slicing

2. Métodos de Listas

estudiantes = ["Ana", "Luis", "María"]
estudiantes.append("Carlos")
estudiantes.insert(1, "Sofía")
print(estudiantes)

estudiantes.remove("Luis")
print("Después de remove:", estudiantes)

3. Recorrido y Acumulaciones

notas = [4.0, 3.5, 4.8, 2.9]
suma = 0
for nota in notas:
    suma += nota

promedio = suma / len(notas)
print("Promedio:", round(promedio, 2))

Ejercicio 2

Pide 4 notas al usuario, guárdalas en una lista y calcula el promedio.

notas = []
for i in range(4):
    nota = float(input(f"Nota {i+1}: "))
    notas.append(nota)

print("Promedio:", round(sum(notas)/len(notas), 2))
