Semana 12: Funciones y Diseño Modular

1. Definición y Llamada de Funciones

def saludar(nombre):
    print(f"¡Hola {nombre}! Bienvenido al curso.")

saludar("Ariadna")
saludar("Hever")

2. Parámetros y Valor de Retorno

def sumar(a, b):
    return a + b

def calcular_area_rectangulo(base, altura):
    return base * altura

print("Suma:", sumar(15, 27))
print("Área:", calcular_area_rectangulo(8, 5))

3. Documentación (docstring) y Parámetros por Defecto

def potencia(base, exponente=2):
    """Calcula la potencia de un número"""
    return base ** exponente

print(potencia(5))
print(potencia(3, 4))

✍️ Ejercicios Propuestos

Ejercicio 1

Crea una función que reciba dos números y retorne el mayor.

def mayor_de_dos(a, b):
    if a > b:
        return a
    else:
        return b

print(mayor_de_dos(15, 27))

Ejercicio 2

Crea una función que calcule el promedio de una lista de números.

def calcular_promedio(lista):
    if len(lista) == 0:
        return 0
    return sum(lista) / len(lista)

notas = [4.2, 3.8, 4.5, 3.1]
print("Promedio:", round(calcular_promedio(notas), 2))

Ejercicio 3

Crea una función que convierta Celsius a Fahrenheit.

def celsius_a_fahrenheit(c):
    return (c * 9/5) + 32

print("30°C =", celsius_a_fahrenheit(30), "°F")
