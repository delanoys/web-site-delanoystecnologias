🔍 Ejemplos Integradores (Repaso Final)

# Ejemplo 1: Sistema de Notas con Diccionario + Funciones
def registrar_nota(estudiantes, nombre, nota):
    estudiantes[nombre] = nota

estudiantes = {}
registrar_nota(estudiantes, "Ariadna", 4.5)
registrar_nota(estudiantes, "Hever", 4.2)

print("Registro:", estudiantes)
print("Promedio:", round(sum(estudiantes.values())/len(estudiantes), 2))
# Ejemplo 2: Guardar y leer desde archivo
with open("final.txt", "w") as f:
    f.write("Curso Python Fundamentos - Ariadna\n")
    f.write("Estudiante: Hever - Nota Final: 4.8\n")

with open("final.txt", "r") as f:
    print(f.read())

Ejercicio 1 (Nivel Avanzado)

Crea un programa que gestione estudiantes con diccionario y guarde en archivo.

estudiantes = {}
estudiantes["Ana"] = 4.5
estudiantes["Luis"] = 3.9

with open("notas_finales.txt", "w") as f:
    for nombre, nota in estudiantes.items():
        f.write(f"{nombre},{nota}\n")

print("Datos guardados correctamente.")

Ejercicio 2

Ordena una lista de tuplas (nombre, nota) de mayor a menor nota.

alumnos = [("Ana", 4.5), ("Pedro", 3.2), ("María", 4.8), ("Luis", 4.1)]
ordenados = sorted(alumnos, key=lambda x: x[1], reverse=True)
print(ordenados)

Ejercicio 3 (Proyecto Final)

Crea una función que busque un estudiante y muestre su información.

def buscar_estudiante(agenda, nombre):
    return agenda.get(nombre, "Estudiante no encontrado")

agenda = {"Ariadna": 4.7, "Hever": 4.5}
print(buscar_estudiante(agenda, "Ariadna"))
