Semana 14: Manipulación y Ordenamiento de Datos

1. Métodos sort() y sorted()

notas = [3.8, 4.5, 2.9, 4.1, 3.2]

notas.sort()                    # Ordena la lista original
print(notas)

ordenado = sorted(notas, reverse=True)
print("Descendente:", ordenado)

2. Ordenamiento con clave (key)

estudiantes = [("Ana", 4.2), ("Luis", 3.5), ("María", 4.8)]

# Ordenar por nota (segundo elemento)
estudiantes_ordenados = sorted(estudiantes, key=lambda x: x[1], reverse=True)
print(estudiantes_ordenados)

3. Algoritmo Básico de Ordenamiento (Burbuja)

def bubble_sort(lista):
    n = len(lista)
    for i in range(n):
        for j in range(0, n-i-1):
            if lista[j] > lista[j+1]:
                lista[j], lista[j+1] = lista[j+1], lista[j]
    return lista

print(bubble_sort([64, 34, 25, 12, 22, 11, 90]))

Ejercicio 3

Crea una función que ordene una lista usando el algoritmo de selección.

def selection_sort(lista):
    for i in range(len(lista)):
        min_idx = i
        for j in range(i+1, len(lista)):
            if lista[j] < lista[min_idx]:
                min_idx = j
        lista[i], lista[min_idx] = lista[min_idx], lista[i]
    return lista

print(selection_sort([64, 25, 12, 22, 11]))
