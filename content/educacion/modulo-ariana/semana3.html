Semana 3: Lógica Básica - Condicional Simple (if)

1. Expresiones Booleanas y Operadores Relacionales

edad = 18
print(edad >= 18)        # True
print(edad < 18)         # False
print(edad == 20)        # False

2. Condicional Simple if

edad = 20

if edad >= 18:
    print("Eres mayor de edad")
    print("Puedes votar")

3. Operadores Lógicos (and, or, not)

nota = 4.2
asistencia = 85

if nota >= 3.0 and asistencia >= 80:
    print("Aprobaste el curso")
else:
    print("Necesitas mejorar")

✍️ Ejercicios Propuestos

Ejercicio 1

Pide la edad del usuario e indica si es mayor o menor de edad.

edad = int(input("Ingresa tu edad: "))

if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

Ejercicio 2

Pide una nota y determina si aprobó (nota ≥ 3.0).

nota = float(input("Ingresa tu nota: "))

if nota >= 3.0:
    print("¡Felicidades! Aprobaste")
else:
    print("Necesitas estudiar más")

Ejercicio 3

Determina si un número es positivo, negativo o cero.

num = int(input("Ingresa un número: "))

if num > 0:
    print("El número es positivo")
elif num < 0:
    print("El número es negativo")
else:
    print("El número es cero")
