Semana 10: Segundo Parcial

📌 Semana de Segundo Parcial
Repasa los temas de las semanas 1 al 9.

Temas Evaluados en el Segundo Parcial

  • Listas y Tuplas
  • Conjuntos
  • Ciclos (for y while)
  • Condicionales avanzados
  • Entrada/Salida y manejo de datos

🔍 Ejemplos de Repaso Integrador

# Ejemplo 1: Listas + Ciclos
notas = [4.2, 3.1, 4.8, 2.9, 4.0]
aprobados = []

for nota in notas:
    if nota >= 3.0:
        aprobados.append(nota)

print("Aprobados:", aprobados)
print("Promedio general:", round(sum(notas)/len(notas), 2))
# Ejemplo 2: Conjuntos + Condicionales
grupo_a = {"Ana", "Luis", "María"}
grupo_b = {"Luis", "Pedro", "Sofía"}

comunes = grupo_a & grupo_b
print("Estudiantes en ambos grupos:", comunes)

✍️ Ejercicios de Repaso para el Parcial

Ejercicio 1

Pide 5 números, guárdalos en una lista y muestra el mayor y el menor.

numeros = []
for i in range(5):
    num = int(input(f"Número {i+1}: "))
    numeros.append(num)

print("Mayor:", max(numeros))
print("Menor:", min(numeros))

Ejercicio 2

Elimina los números duplicados de una lista usando conjuntos.

datos = [1, 2, 2, 3, 4, 4, 5, 1, 6]
unicos = list(set(datos))
print("Sin duplicados:", unicos)

Ejercicio 3 (Nivel Parcial)

Crea un programa que pida números hasta que el usuario ingrese 0 y calcule su promedio.

numeros = []
while True:
    num = int(input("Ingresa un número (0 para terminar): "))
    if num == 0:
        break
    numeros.append(num)

if numeros:
    print("Promedio:", round(sum(numeros)/len(numeros), 2))
else:
    print("No se ingresaron números")
