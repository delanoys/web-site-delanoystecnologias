Semana 9: Conjuntos (Sets) en Python

1. Creación y Propiedades de Conjuntos

frutas = {"manzana", "banana", "cereza", "manzana"}
print(frutas)                    # No permite duplicados
print(len(frutas))

numeros = set([1, 2, 2, 3, 4, 4])
print(numeros)

2. Operaciones Básicas con Conjuntos

A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print(A | B)   # Unión
print(A & B)   # Intersección
print(A - B)   # Diferencia
print(A ^ B)   # Diferencia simétrica

3. Métodos Útiles

estudiantes = {"Ana", "Luis", "María"}
estudiantes.add("Carlos")
print(estudiantes)

estudiantes.discard("Luis")   # No da error si no existe
print("Después de discard:", estudiantes)

print("Unión:", A | B)

Ejercicio 2

Elimina duplicados de una lista usando un conjunto.

lista = [1, 2, 2, 3, 4, 4, 5, 1]
sin_duplicados = set(lista)
print(list(sin_duplicados))

Ejercicio 3

Verifica si dos conjuntos son disjuntos (no tienen elementos en común).

grupo1 = {"Ana", "Luis", "Pedro"}
grupo2 = {"María", "Sofía", "Carlos"}

if grupo1.isdisjoint(grupo2):
    print("No tienen estudiantes en común")
else:
    print("Tienen estudiantes en común")
