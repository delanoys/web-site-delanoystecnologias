Semana 4: Estructuras Selectivas (if / else / elif)

1. Condicional Doble (if - else)

nota = 3.8

if nota >= 3.0:
    print("Aprobado")
else:
    print("Reprobado")

2. Condicional Múltiple (elif)

nota = 4.2

if nota >= 4.5:
    print("Excelente")
elif nota >= 3.5:
    print("Bueno")
elif nota >= 3.0:
    print("Aceptable")
else:
    print("Insuficiente")

3. Condicionales Anidados

edad = 16
tiene_permiso = True

if edad >= 18:
    print("Puede entrar")
else:
    if tiene_permiso:
        print("Puede entrar con permiso")
    else:
        print("No puede entrar")

✍️ Ejercicios Propuestos

Ejercicio 1

Pide una nota y clasifícala según rangos (Insuficiente, Aceptable, Bueno, Excelente).

nota = float(input("Ingresa tu nota: "))

if nota >= 4.5:
    print("Excelente")
elif nota >= 3.5:
    print("Bueno")
elif nota >= 3.0:
    print("Aceptable")
else:
    print("Insuficiente")

Ejercicio 2

Determina si un número está en el rango de 1 a 100.

num = int(input("Ingresa un número: "))

if num >= 1 and num <= 100:
    print("El número está dentro del rango")
else:
    print("El número está fuera del rango")

Ejercicio 3

Crea un menú simple: 1. Sumar, 2. Restar, 3. Salir.

opcion = int(input("1. Sumar\n2. Restar\n3. Salir\nElige: "))

if opcion == 1:
