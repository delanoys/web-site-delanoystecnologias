Semana 6: Iteraciones y Ciclos

1. Ciclo for

for i in range(5):
    print("Iteración:", i)

print("---")

for num in [10, 20, 30, 40]:
    print(num)

2. Ciclo while

contador = 1
while contador <= 5:
    print("Contador:", contador)
    contador += 1

3. break, continue y acumuladores

suma = 0
for i in range(1, 11):
    if i == 5:
        continue          # Salta el 5
    suma += i
print("Suma:", suma)

✍️ Ejercicios Propuestos

Ejercicio 1

Imprime los números del 1 al 20 usando un ciclo for.

for i in range(1, 21):
    print(i, end=" ")

Ejercicio 2

Pide un número n y calcula la suma de los primeros n números naturales.

n = int(input("Ingresa un número: "))
suma = 0
for i in range(1, n+1):
    suma += i
print("La suma es:", suma)

Ejercicio 3

Imprime la tabla de multiplicar de un número ingresado por el usuario.

num = int(input("Ingresa un número: "))
for i in range(1, 11):
    print(f"{num} x {i} = {num * i}")
