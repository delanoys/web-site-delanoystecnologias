Semana 11: Diccionarios (key-value)

1. Creación y Acceso a Diccionarios

estudiante = {
    "nombre": "Ariadna",
    "edad": 20,
    "carrera": "Ingeniería",
    "notas": [4.2, 3.8, 4.5]
}

print(estudiante["nombre"])
print(estudiante.get("edad"))

2. Métodos de Diccionarios

persona = {"nombre": "Hever", "edad": 22}
persona["ciudad"] = "San Pablo"
persona.update({"profesion": "Estudiante"})

print(persona.keys())
print(persona.values())
print("edad" in persona)

3. Diccionarios Anidados y Recorrido

curso = {
    "nombre": "Python",
    "estudiantes": {
        "001": {"nombre": "Ana", "nota": 4.5},
        "002": {"nombre": "Luis", "nota": 3.9}
    }
}

for codigo, info in curso["estudiantes"].items():
    print(f"{codigo}: {info['nombre']} - Nota: {info['nota']}")

✍️ Ejercicios Propuestos

Ejercicio 1

Crea un diccionario con información personal y muestra todos los valores.

persona = {
    "nombre": "Hever",
    "edad": 22,
    "ciudad": "San Pablo",
    "carrera": "Programación"
}

print(persona["nombre"])
for clave, valor in persona.items():
    print(f"{clave}: {valor}")

Ejercicio 2

Crea un diccionario de notas y calcula el promedio.

notas = {"matematicas": 4.2, "fisica": 3.8, "quimica": 4.5}
promedio = sum(notas.values()) / len(notas)
print("Promedio:", round(promedio, 2))
