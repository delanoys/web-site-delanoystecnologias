📌 Ruta de Aprendizaje - Proyecto Web Completo

Guía de temas a reforzar con enlaces a cursos de Udemy y MinTIC.

1️⃣ Fundamentos Web

  • HTML5 & Semántica
  • CSS3 (Flexbox, Grid, Bootstrap, SASS)
  • JavaScript (ES6+)
  • Git + GitHub (control de versiones)

2️⃣ Frontend Moderno

  • React (componentes, hooks, routing)
  • Manejo de estado (Context API / Redux)
  • Consumo de APIs REST

3️⃣ Backend con Python

  • Python avanzado (POO, librerías)
  • Django o FastAPI (APIs REST, autenticación)
  • ORM (Django ORM o SQLAlchemy)

4️⃣ Bases de Datos

  • SQL (PostgreSQL / MySQL)
  • Diseño de tablas (clientes, facturas)
  • Conexión Backend - DB

5️⃣ Proyecto: Módulo de Clientes + Facturación

  • Formulario de registro de clientes
  • API de clientes y facturas
  • Generación de facturas en PDF
  • Envío de correos automáticos

6️⃣ Despliegue y Cloud

  • Deploy Frontend (Vercel / Netlify)
  • Deploy Backend (Railway / Render / AWS / GCP)
  • Base de datos en la nube (Supabase / AWS RDS / CloudSQL)

7️⃣ Extras

  • Seguridad y Ciberseguridad
  • Machine Learning e IA aplicada
  • Optimización y buenas prácticas
