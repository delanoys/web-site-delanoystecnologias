**DevOps** es una combinación de filosofías culturales, prácticas y herramientas que aumentan la capacidad de una organización para entregar aplicaciones y servicios a alta velocidad. Esta velocidad permite a las organizaciones atender mejor a sus clientes y competir de manera más efectiva en el mercado.

Conceptos Clave en DevOps

Integración y Entrega Continua (CI/CD)

**CI** es la práctica de fusionar cambios de código regularmente, ejecutando pruebas automáticas. **CD** extiende esto, asegurando que cada cambio sea liberable a producción.

Automatización del 'Build' y 'Test'.

Microservicios y APIs

La arquitectura de **Microservicios** descompone una aplicación en servicios pequeños e independientes. Las **APIs** (Application Programming Interfaces) son el medio por el cual estos servicios se comunican entre sí.

Fundamental para la escalabilidad moderna.

Infraestructura como Código (IaC)

Gestión de la infraestructura (redes, máquinas virtuales, bases de datos) utilizando código y archivos de configuración. Clave para la **repetibilidad** y la **consistencia**.

Herramientas: Terraform, Ansible.

Principios Clave de DevOps (CAMS)

Los principios de DevOps a menudo se resumen en el acrónimo CAMS:

  • Cultura y Colaboración: Fomentar la comunicación y la responsabilidad compartida entre Dev y Ops.
  • Automatización: Eliminar tareas manuales en todo el pipeline (CI/CD, IaC, Pruebas).
  • Medición (Metrics): Monitorear y recopilar datos para obtener retroalimentación continua sobre el rendimiento y la experiencia del usuario.
  • Compartir (Sharing): Compartir conocimiento, herramientas y procesos entre equipos para el aprendizaje continuo.

Herramientas Comunes en DevOps

El ecosistema de herramientas es vasto. Aquí están los pilares fundamentales para cada fase:

Control de Versiones

**Git, GitHub/GitLab:** La base de todo. Permite la colaboración, el seguimiento de cambios y la integración con CI/CD.

Explorar Git

CI/CD y Automatización

**Jenkins, GitHub Actions, GitLab CI/CD:** Orquestan y automatizan el proceso de compilación, prueba y despliegue del software.

Ver Jenkins

Contenedores y Orquestación

**Docker, Kubernetes (K8s):** Empaquetan aplicaciones de manera consistente y gestionan su escalabilidad y despliegue en cualquier entorno.

Ver K8s

Infraestructura como Código

**Terraform, Ansible:** Permiten definir, aprovisionar y gestionar la infraestructura cloud (AWS, Azure, GCP) mediante código declarativo.

Ver Terraform

Monitoreo y Logging

**Prometheus, Grafana, ELK Stack:** Recolectan métricas y logs en tiempo real para observar el comportamiento del sistema en producción.

Ejercicios Prácticos para Empezar

Aplica los conceptos de inmediato. Necesitarás tener **Git** y **Docker** instalados.

Ejercicio 1: Configuración de CI Simple (GitHub Actions)

Pasos Clave

  1. Crea un repositorio en GitHub.
  2. Añade un archivo simple (`hello.py`).
  3. Crea la carpeta `.github/workflows/`.
  4. Crea el archivo `main.yml` para definir un *workflow* de "Build" y "Test" automático al hacer `git push`.

Objetivo: Ver cómo una acción de código dispara la automatización del *pipeline*.

Ejercicio 2: Dockerización de una Aplicación

Pasos Clave

  1. Crea un archivo `app.py` (ej. usando Flask).
  2. Define un `Dockerfile` base que incluya la imagen, dependencias y comando de ejecución.
  3. Construye la imagen: docker build -t mi-app-devops .
  4. Ejecuta y verifica: docker run -p 5000:5000 mi-app-devops

Objetivo: Crear un artefacto inmutable y portable.

Ejercicio 3: Despliegue con Docker Compose (Microservicios)

Pasos Clave

  1. Crea dos carpetas separadas (`service1` y `service2`), cada una con su propia app y `Dockerfile`.
  2. Define un archivo central `docker-compose.yml` que orqueste la construcción y ejecución de ambos servicios.
  3. Levanta todo: docker-compose up --build

Objetivo: Simular una arquitectura de microservicios con orquestación básica.

Beneficios Clave de DevOps

**Mayor Velocidad** y fiabilidad en las entregas de software.

**Mejor Colaboración** y menor fricción entre equipos.

**Reducción de Costos** operativos gracias a la automatización.

**Seguridad Mejorada** al integrar prácticas (DevSecOps) desde el inicio.
