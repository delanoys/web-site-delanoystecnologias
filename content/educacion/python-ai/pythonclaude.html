Historia y Evolución de Python 🐍

¿Qué es Python?

Python es un lenguaje de programación de alto nivel, interpretado y de propósito general. Su filosofía de diseño enfatiza la legibilidad del código con el uso de sangría significativa.

Línea de Tiempo

1989

Inicio: Guido van Rossum comenzó a trabajar en Python durante la Navidad en el Centro de Matemáticas e Informática (CWI) en los Países Bajos.

1991

Lanzamiento: Python 0.9.0 fue publicado. Ya incluía clases, manejo de excepciones y funciones.

2000

Python 2.0: Introducción de list comprehensions y recolección de basura con conteo de referencias.

2008

Python 3.0: Rediseño importante que no era compatible con Python 2.x. Mejoró la consistencia del lenguaje.

2020

Fin de Python 2: Python 2.7 dejó de recibir soporte oficial, marcando la transición completa a Python 3.

2025

Actualidad: Python se mantiene como uno de los lenguajes más populares, con Python 3.13 siendo la versión más reciente.

¿Por qué Python es tan importante hoy?

Python es uno de los lenguajes de programación más populares según índices como TIOBE y Stack Overflow.

Nivel Avanzado Avanzado

1. Decoradores

def mi_decorador(func):
    def wrapper(*args, **kwargs):
        print("Antes de la función")
        resultado = func(*args, **kwargs)
        print("Después de la función")
        return resultado
    return wrapper

@mi_decorador
def saludar(nombre):
    print(f"¡Hola, {nombre}!")

saludar("Python")

2. Generadores

def fibonacci(n):
    a, b = 0, 1
    count = 0
    while count < n:
        yield a
        a, b = b, a + b
        count += 1

for num in fibonacci(10):
    print(num, end=" ")

3. Context Managers

from contextlib import contextmanager

@contextmanager
def gestor_archivo(nombre):
    archivo = open(nombre, 'w')
    try:
        yield archivo
    finally:
        archivo.close()

with gestor_archivo('test.txt') as f:
    f.write('Hola mundo')

4. Programación Funcional

from functools import reduce

numeros = [1, 2, 3, 4, 5]

# Map: aplicar función a cada elemento
cuadrados = list(map(lambda x: x**2, numeros))

# Filter: filtrar elementos
pares = list(filter(lambda x: x % 2 == 0, numeros))

# Reduce: reducir a un solo valor
suma = reduce(lambda x, y: x + y, numeros)
print(cuadrados, pares, suma)

async def tarea_lenta(nombre, segundos):

async def main():

def calculadora(a, b, operacion):
    if operacion == "+":
        return a + b
    elif operacion == "-":
        return a - b
    elif operacion == "*":
        return a * b
    elif operacion == "/":

def es_palindromo(palabra):
    palabra = palabra.lower().replace(" ", "")
    return palabra == palabra[::-1]

print(es_palindromo("anilina")) # True
print(es_palindromo("python")) # False

Ejercicio 1: Gestión de Estudiantes

Crea una clase para gestionar estudiantes y sus calificaciones.

class Estudiante:
    def __init__(self, nombre):
        self.nombre = nombre
        self.calificaciones = []

    def agregar_nota(self, nota):
        self.calificaciones.append(nota)

    def promedio(self):
        if len(self.calificaciones) == 0:
            return 0
        return sum(self.calificaciones) / len(self.calificaciones)

Ejercicio 1: Sistema de Cache con Decoradores

Implementa un sistema de cache para optimizar funciones.

def cache(func):
    memoria = {}
    def wrapper(*args):
        if args in memoria:
            print(f"Usando cache para {args}")
            return memoria[args]
        resultado = func(*args)
        memoria[args] = resultado
        return resultado
    return wrapper

@cache
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

Ejercicio 2: API REST Simple

Estructura básica de una API con manejo de datos.

class APISimple:
    def __init__(self):
        self.datos = {}

    def crear(self, id, datos):
        self.datos[id] = datos
        return {"status": "creado", "id": id}

    def leer(self, id):
        return self.datos.get(id, "No encontrado")

    def actualizar(self, id, datos):
        if id in self.datos:
            self.datos[id] = datos
            return {"status": "actualizado"}
        return {"status": "error"}

    def eliminar(self, id):
        if id in self.datos:
            del self.datos[id]
            return {"status": "eliminado"}
        return {"status": "error"}
