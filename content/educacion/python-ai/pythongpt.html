📖 Introducción e historia

Python es un lenguaje de programación de alto nivel creado por Guido van Rossum en 1991. Su diseño enfatiza la legibilidad del código y la simplicidad, siendo ideal tanto para principiantes como para desarrolladores avanzados. Ha evolucionado significativamente desde sus primeras versiones, y hoy en día es ampliamente utilizado en desarrollo web, análisis de datos, inteligencia artificial, automatización y más.

💡 ¿Por qué Python?

  • Legible y fácil de aprender.
  • Gran comunidad y amplio ecosistema de librerías.
  • Versatilidad en múltiples áreas: ciencia de datos, web, automatización, IA, etc.

🎯 Conceptos básicos

Python permite trabajar con variables, tipos de datos, estructuras de control y funciones de manera simple:

# Declaración de variables y tipos
nombre = "Juan"
edad = 25
pi = 3.14

# Función básica
def saludar(nombre):
    return f"Hola, {nombre}!"

print(saludar(nombre))

🚀 Temas avanzados

Python ofrece características avanzadas como clases y objetos, manejo de excepciones, decoradores, generadores y comprensión de listas.

# Clase y método en Python
class Persona:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad

    def saludar(self):
        return f"Hola, soy {self.nombre} y tengo {self.edad} años"

juan = Persona('Juan', 30)
print(juan.saludar())

# Comprensión de listas
cuadrados = [x**2 for x in range(5)]
print(cuadrados)
