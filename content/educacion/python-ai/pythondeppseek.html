¿Qué es Python?

Python es un lenguaje de programación interpretado, de alto nivel y con una sintaxis clara y legible. Es multiparadigma, lo que significa que soporta programación orientada a objetos, imperativa y funcional.

Historia y Evolución de Python

Python fue creado a finales de los años 80 por Guido van Rossum en los Países Bajos. Su diseño prioriza la legibilidad del código y permite a los programadores expresar conceptos en menos líneas de código que en lenguajes como C++ o Java.

1989

Guido van Rossum comienza a trabajar en Python como un proyecto de hobby durante las vacaciones de Navidad.

1991

Se publica la primera versión de Python (0.9.0) que ya incluía clases con herencia, manejo de excepciones, funciones y los tipos de datos fundamentales.

2000

Se lanza Python 2.0 con nuevas características como list comprehensions y un sistema de recolección de basura.

2008

Python 3.0 (también llamado "Python 3000") se lanza como una revisión importante del lenguaje que no es totalmente compatible con versiones anteriores.

2020

Python 2.7 llega al final de su vida útil, marcando la transición completa a Python 3.

Conceptos Básicos de Python

Variables y Tipos de Datos

En Python, no es necesario declarar el tipo de variable. El intérprete infiere el tipo automáticamente.

# Ejemplos de variables
nombre = "Ana" # String
edad = 25 # Integer
altura = 1.75 # Float
es_estudiante = True # Boolean

Estructuras de Control

Python utiliza indentación para definir bloques de código, lo que mejora la legibilidad.

# Condicional if
if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")

# Bucle for
for i in range(5):
    print(i)

# Bucle while
contador = 0
while contador < 5:
    print(contador)
    contador += 1

Conceptos Avanzados de Python

Programación Orientada a Objetos

Python soporta completamente la programación orientada a objetos, incluyendo herencia múltiple.

# Definición de una clase
class Persona:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad

    def presentarse(self):
        return f"Hola, me llamo {self.nombre} y tengo {self.edad} años"

# Creación de un objeto
persona1 = Persona("María", 30)
print(persona1.presentarse())

Manejo de Excepciones

Python proporciona un mecanismo robusto para manejar errores y excepciones.

try:
    numero = int("abc") # Esto generará un ValueError
except ValueError:
    print("No se puede convertir 'abc' a número")
finally:
    print("Este bloque siempre se ejecuta")

Aplicaciones de Python en la Actualidad

Python es uno de los lenguajes más versátiles y se utiliza en una amplia gama de aplicaciones:

Desarrollo Web

Frameworks como Django y Flask permiten crear aplicaciones web robustas y escalables.

Ciencia de Datos

Librerías como Pandas, NumPy y Scikit-learn hacen de Python el lenguaje preferido para análisis de datos y machine learning.

Automatización

Python es ideal para scripts de automatización de tareas, desde simples hasta complejas.

Inteligencia Artificial

TensorFlow, PyTorch y Keras son algunas de las librerías de IA más populares construidas en Python.

Desarrollo de Juegos

Aunque no es el lenguaje principal, Python se utiliza con librerías como Pygame para desarrollar juegos.

Internet de las Cosas (IoT)

Python es popular en proyectos de IoT debido a su simplicidad y la disponibilidad de librerías para hardware.
