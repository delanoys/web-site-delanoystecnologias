2. ¿Qué es OpenClaw?

Definición Técnica

OpenClaw es una plataforma de agente personal open-source que se ejecuta en tu propio hardware (self-hosted) y puede realizar tareas autónomamente en tu nombre. Con más de 100,000 estrellas en GitHub, se ha convertido en la herramienta de IA más popular de 2026.

Mejores Prácticas de Seguridad Obligatorias

# 1. NUNCA ejecutar como root
useradd -m -s /bin/bash openclaw

# 2. SIEMPRE usar Docker (aislamiento)
docker run --security-opt=no-new-privileges ...

# 3. Bind solo a localhost (no exponer a internet)

# 4. Sandbox mode activado
OPENCLAW_SECURITY_MODE=sandbox

# 5. Restringir herramientas permitidas
OPENCLAW_ALLOWED_TOOLS="read_file,web_search,execute_code"

# 6. Auditoría de logs
docker logs --follow openclaw

# 7. Límites de recursos
mem_limit: 2g
cpus: 1.0

watchtower/watchtower:latest

Configuración Recomendada - Docker en VPS Hostinger

version: '3.8'
services:
  openclaw:
    image: openclaw/openclaw:latest
    ports:
      - "127.0.0.1:3000:3000"  # Solo localhost
    volumes:
      - ./data:/app/data
      - ./skills:/app/skills
      - ./logs:/app/logs
    environment:
      - OPENCLAW_SECURITY_MODE=sandbox
      - OPENCLAW_ALLOWED_TOOLS=read_file,web_search,execute_code,shell
      - QWEN_API_KEY=${QWEN_API_KEY}
      - DEEPSEEK_API_KEY=${DEEPSEEK_API_KEY}
      - OPENAI_API_KEY=${OPENAI_API_KEY:-}  # Opcional
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY:-}  # Opcional
    security_opt:
      - no-new-privileges:true
    restart: unless-stopped
    user: "1000:1000"  # No root
    mem_limit: 2g  # Límite de RAM
    cpus: 1.0  # Límite de CPU

8. Integración con Pipeline IA PRO V6

Filosofía Central

"No desarrollamos aplicaciones. Desarrollamos Frameworks."

Pipeline IA PRO V6 incorpora un cambio de paradigma fundamental: desarrollar Frameworks en lugar de aplicaciones aisladas. Cada proyecto exitoso se convierte en un activo tecnológico reutilizable.

Principios Fundamentales

  • Principio #1: Ninguna fase puede avanzar si la anterior no está aprobada y documentada
  • Principio #2 (V6): Antes de escribir código, responder: ¿Existe un Framework que resuelva esto?
  • Principio #3 (V6): Todo proyecto debe evolucionar hacia un Framework reutilizable

FASE 0: Ingeniería de Reutilización

Sistema Inventario Restaurante (El Sazón del Boulevard) │ ▼ Framework Inventario DT │ ┌──────────────┼──────────────┐ ▼ ▼ ▼ Restaurante Ferretería Papelería ▼ ▼ ▼ Boutique Supermercado Miscelánea ▼ Variedades Mis Nietos

Sistema Multi-IA con Copilotos Permanentes

El Pipeline IA PRO V6 implementa una arquitectura colaborativa donde cada fase cuenta con:

  • Responsable principal (según la fase)
  • Deep → Copiloto Técnico Permanente
  • Qwen → Copiloto Técnico Permanente
