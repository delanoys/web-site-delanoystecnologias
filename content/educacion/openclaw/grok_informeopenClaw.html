Instalación Paso a Paso en Elementary OS 8 (Recomendada)

Paso 1: Instalar Docker

sudo apt update
sudo apt install docker.io docker-compose -y
sudo usermod -aG docker $USER
newgrp docker

Paso 2: Crear estructura de carpetas

mkdir -p ~/openclaw/data
mkdir -p ~/openclaw/projects-backup
mkdir -p ~/openclaw/projects-active

Paso 3: docker-compose.yml (Seguro)

version: '3.8'
services:
  openclaw:
    image: openclaw/openclaw:latest
    user: "1000:1000"
    ports:
      - "18789:18789"
    volumes:
      - openclaw-data:/root/.openclaw
      - ~/openclaw/projects-backup:/projects:ro
      - ~/openclaw/projects-active:/active-projects
    environment:
      - TZ=America/Bogota
