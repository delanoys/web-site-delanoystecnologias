01 • FUNDAMENTOS

¿Qué es DiskPart y cómo funciona?

DiskPart es una utilidad de línea de comandos integrada en Windows que permite gestionar discos, particiones y volúmenes de forma avanzada. Es mucho más potente que la herramienta gráfica "Administración de discos" y es especialmente útil en entornos de recuperación o durante la instalación de Windows.

Características principales
  • Crear, eliminar y modificar particiones
  • Convertir entre MBR y GPT
  • Asignar letras de unidad y formatear
  • Limpiar discos completamente
  • Trabajar con discos dinámicos y básicos
  • Automatizable mediante scripts

DiskPart funciona directamente sobre el tabla de particiones del disco (MBR o GPT). Cuando ejecutas el comando clean, elimina toda la información de particionado del disco seleccionado, dejando el espacio como "No asignado". Esto resuelve la mayoría de problemas donde el instalador de Windows no reconoce las particiones.

⚠️ ADVERTENCIA CRÍTICA - PÉRDIDA DE DATOS

El uso incorrecto de DiskPart puede causar la pérdida PERMANENTE E IRREVERSIBLE de todos tus datos.

Antes de continuar, confirma lo siguiente:

  • Has realizado respaldo completo de cualquier dato importante en el disco que vas a limpiar.
  • Estás 100% seguro de cuál es el número del disco SSD SATA que deseas limpiar.
  • No tienes particiones con datos en otros discos que puedas seleccionar por error.
  • El disco que vas a limpiar es el que NO contiene tu sistema operativo actual (si estás en Windows).

Delanoys Tecnologías no se hace responsable por pérdida de información derivada del uso de esta guía.

03 • PREPARACIÓN

Cómo acceder a DiskPart desde el instalador de Windows

1

Inicia desde el USB de Windows

Inserta tu USB de instalación de Windows 10 o 11 y arranca tu PC desde él (cambia el orden de arranque en BIOS/UEFI si es necesario).

2

Llega a la pantalla de particiones

Avanza hasta la pantalla donde se muestran las particiones del disco ("¿Dónde quieres instalar Windows?").

3

Abre el Símbolo del sistema

Presiona las teclas Shift + F10 simultáneamente. Se abrirá una ventana negra de CMD.

04 • ACCIÓN INMEDIATA

Procedimiento Paso a Paso
para Limpiar tu SSD SATA

Sigue estos pasos exactamente en el orden indicado.

Recomendado para SSD
1

Iniciar DiskPart

diskpart

Escribe diskpart y presiona Enter. Aparecerá el prompt DISKPART>

2

Listar los discos disponibles

list disk

IDENTIFICA TU SSD SATA

Mira la columna Tamaño. Tu SSD SATA aparecerá con su capacidad real (ej: 240 GB, 500 GB, 1 TB). NO selecciones el disco del USB del instalador (suele aparecer como "Removable" o muy pequeño).

Ejemplo de salida:

  Disco ###  Estado         Tamaño     Libre     Dinámico  GPT
  --------  -------------  --------  --------  --------  ---
  Disco 0    En línea         476 GB      0 B
  Disco 1    En línea         931 GB    931 GB           *
3

¡SELECCIONA EL DISCO CORRECTO!

select disk X

Reemplaza X con el número de tu SSD (ej: select disk 0 o select disk 1).

VERIFICA DOS VECES el número antes de presionar Enter. Si tienes dudas, escribe list disk nuevamente.
4

Limpiar el disco (Eliminar particiones)

clean

Este comando elimina todas las particiones y datos del disco seleccionado.

Es la opción recomendada y más rápida para preparar un disco para una nueva instalación de Windows.

5

Salir de DiskPart

exit

Cierra DiskPart. Ahora puedes cerrar la ventana de CMD o presionar Alt + Tab para volver al instalador de Windows.

Consejo profesional: Después de ejecutar clean, regresa a la pantalla de particiones del instalador y haz clic en "Actualizar". El disco debería aparecer ahora como "Espacio no asignado".
05 • COMPARACIÓN

Diferencia entre clean y clean all

RECOMENDADO
clean
  • Elimina la tabla de particiones (MBR/GPT)
  • Muy rápido (segundos)
  • Suficiente para instalación limpia de Windows
  • Deja el disco como "No asignado"
Usa este para la mayoría de casos de reinstalación.
AVANZADO
clean all
  • Elimina particiones + sobrescribe cada sector con ceros
  • Muy lento (puede tardar horas en SSD de 1TB)
  • Borrado seguro (similar a formato de bajo nivel)
  • No es necesario para instalar Windows
Solo úsalo si necesitas borrar datos de forma segura (ej. vender el disco).
06 • REFERENCIA RÁPIDA

Comandos esenciales de DiskPart

Comando Descripción Cuándo usarlo
list disk Muestra todos los discos físicos conectados Siempre el primer paso
select disk X Selecciona el disco número X para trabajar con él Después de identificar el disco correcto
list partition Lista las particiones del disco seleccionado Para verificar antes de limpiar
clean Elimina todas las particiones del disco seleccionado Para preparación de instalación
clean all Limpieza completa (sobrescribe sectores) Solo para borrado seguro
create partition primary Crea una partición primaria nueva Si quieres crear particiones manualmente
format fs=ntfs quick Formatea la partición seleccionada como NTFS Después de crear partición manual
exit Sale de DiskPart Al finalizar
07 • SIGUIENTE PASO

Qué hacer después de limpiar el disco

  1. 1. Regresa a la pantalla de instalación de Windows (puedes cerrar la ventana de CMD).
  2. 2. Haz clic en el botón "Actualizar" (ícono de flechas).
  3. 3. El disco ahora debe aparecer como "Espacio no asignado" con el tamaño completo de tu SSD.
  4. 4. Selecciona el espacio no asignado y haz clic en "Siguiente".
  5. 5. Windows creará automáticamente las particiones necesarias (EFI, MSR, Windows y Recuperación). ¡No es necesario crearlas manualmente!
08 • TROUBLESHOOTING

Solución de problemas comunes

El instalador sigue sin reconocer el disco después de clean

• Verifica en BIOS que el modo SATA esté en AHCI (no RAID/Intel RST).
• Asegúrate de que el modo de arranque sea UEFI (no Legacy).
• Prueba otro puerto SATA o cable de datos.

Aparece error "No se puede instalar Windows en este disco"

Normalmente se resuelve con el comando clean. Si persiste, intenta convertir a GPT: convert gpt después de seleccionar el disco (solo si el disco está limpio).

Seleccioné el disco equivocado

Si aún no has reiniciado ni instalado nada, es posible recuperar particiones con herramientas como TestDisk o EaseUS. Pero actúa rápido. Si ya instalaste Windows encima, los datos anteriores están perdidos.
