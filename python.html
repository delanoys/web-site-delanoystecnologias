Tip de Ejecución en Linux

Para lanzar la interfaz gráfica (Navigator) de forma segura en elementary OS:

  1. Regresa al entorno base: conda activate base
  2. Lanza la aplicación: anaconda-navigator

Nota: Una vez abierto, puedes volver a tu entorno de desarrollo en otra terminal con conda activate dev_pro_CISCO.

Laboratorio Python: Configuración Profesional

Guía técnica para la configuración de entornos de desarrollo en Linux (elementary OS) para proyectos de Ciencia de Datos y Automatización.

1. Creación del Entorno Conda

Aislamiento de dependencias para el curso AvanzaTEC 2026.

# Crear entorno con librerías base
conda create -n dev_pro_CISCO python=3.10 pandas numpy matplotlib scikit-learn

# Activar el entorno
conda activate dev_pro_CISCO
2. Fix Interfaz Gráfica (Linux)

Solución para el error visual de Anaconda Navigator en Wayland.

# Agregar al final de ~/.bashrc
export QT_QPA_PLATFORM=xcb

# Recargar configuración
source ~/.bashrc
3. Arquitectura del Proyecto

Estructura organizada según el temario de Fundamentos de Python 2.

mkdir -p unidades/{u1_modulos,u2_paquetes,u3_errores,u4_diccionarios}
